# 布局与打印调整（2026-09-23）

## 修改

- 概览草稿卡片把继续/删除放入同一操作组，间隔 12px；窄屏移到文字下方。
- OCR 识别预览复用 KaTeX 渲染组件，显示文字与公式混排。
- AI 确认页使用参考信息＋编辑区两栏；编辑区的预览折叠在下方，不再嵌套挤成三栏。模型选择在侧栏纵向排列，保存栏移到页面底部。
- 图片取消 280px 最小高度，按自然比例显示，长图最高 60vh，可打开大图。横向裁剪不会留下固定高度的背景。
- 网页与 APK 的 PDF 导出直接进入题目纸。旧 `with_answers` 链接继续可访问，但同样只输出题目，不输出答案、摘要、标签和时间信息。
- A4 纵向、12mm 页边距，272mm 内容区均分为两个 136mm 题目槽。奇数题的最后一页下半部留空；较长内容按比例缩小，过小时在打印工具栏提示检查字号。工具栏不打印。
- KaTeX 脚本、样式、字体随网页构建和 Go 二进制打包，打印不依赖 CDN。等待公式与字体就绪才启用打印。

## 验证

- Vue 类型检查/生产构建通过；45 项测试通过，包括公式渲染。
- Go 全部测试通过；新增三题分两页、答案隐藏、HTML 转义、旧模式兼容与本地资源断言。
- Flutter 43 项测试通过；分析无 warning/error，保留原有 65 项 info。
- 1440px 浏览器确认页：编辑区保持单栏，模型选择不再挤成小输入框。
- 实际上传 1910×228 横向图片，确认页参考图高度约 38px、容器约 40px，不再撑成 280px。
- 浏览器打印页三题形成两个纸面区，题目槽高度相同；三个公式正常渲染；所有公式资源来自同源 `/print-katex/`。
- 截图：`ui-screenshots/layout-draft-actions.png`、`layout-review-desktop.png`、`layout-print-two-per-a4.png`。

当前验证了 HTML 打印排版与 A4 打印样式，未操作系统“保存 PDF”对话框或物理打印机；未在所有浏览器、手机真机和目标桌面系统执行原生打印。正式打印选择 A4、纵向、100% 缩放并关闭浏览器页眉页脚。超长题目仍应在打印预览检查可读性。
