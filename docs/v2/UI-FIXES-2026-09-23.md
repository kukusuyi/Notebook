# 2.0 UI 问题修复记录（2026-09-23）

分支：`codex/v2.0-ui-refresh`。本次修复沿用 2.0.0，不修改数据库结构。

## 本次变化

1. 网页概览、新增菜单可直接删除未保存草稿，操作前确认；移动端新增菜单增加同样入口，删除后等待本地持久化完成。
2. 网页模型设置增加阿里云注册、百炼控制台和 Qwen 接入说明。Electron 在系统浏览器打开这三个官方站点，其他外部地址仍受限制。
3. 网页图片先预览裁剪再上传，支持拖动框选、四边滑块、保留整张，以及对已上传图片重新裁剪。取消保留当前图片。
4. 网页、Flutter 和服务端统一整理模型/网络错误：密钥、权限、余额、限流、超时、连接、模型不支持、返回格式等；服务端不向客户端返回服务商原始错误正文。
5. 新增错题及其他现有 Vue 对话框挂载到 body，避免玻璃工具栏形成固定定位容器导致遮罩和弹窗被裁切。
6. 网页及 Flutter 的录题、OCR 核对、编辑页面新增“拍照 / 图片识别答案步骤”。使用独立图片和预览，只在用户确认后追加或替换标准答案；替换需确认，不修改题目、错误解法或原题图片。复用 `/api/v1/ocr/wrong-question-json`，新增可选 `purpose: solution`，旧请求默认仍识别题目。

独立提示词：`backend/ocr_solution_prompt.md`，随二进制内嵌。要求只转写图片，不求解、不推理补全、不评价对错。结构不合法的答案识别响应返回友好错误，保留原答案。OpenAPI 已更新。

官方接入说明：[首次调用 Qwen API](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。没有创建阿里云账户或调用付费模型。
